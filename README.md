# Alamaar Case Study Workspace

Working repository for researching, capturing evidence, writing, and QA-ing the Alamaar HPL redesign case study.

## Source sites

- Old site: https://feedbackcentral.site/
- New site: https://alamaarhpl.com/
- Production implementation source: https://github.com/addvaluewithai-hub/alamaarhpl-website
- Portfolio source: https://github.com/addvaluewithai-hub/yasserhawas.site

## Operating rule

The case study must be evidence-led. Do not invent client motivations, outcomes, conversion data, audience research, testimonials, or process artifacts. Separate verified facts from interpretation and open questions.

Start every work session with `tasks/STATUS.md`, then take the next unblocked item in `tasks/BACKLOG.md`. Record any new evidence in `tasks/EVIDENCE.md` and any wording/claim decision in `tasks/CLAIMS.md`.

Automated browser captures live under GitHub Actions artifacts. Curated final media should be uploaded to Cloudinary under `casestudy/alamaar` and recorded in `tasks/EVIDENCE.md`.
